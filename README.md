# 달나라 게임즈 웹사이트

dalnaragames.com 에 올라가는 스튜디오 홈페이지예요.

- `index.html` — 스튜디오 소개, 게임 목록(게임마다 한 줄), 개발 기록, 문의
- `hanmari/` · `tongtong/` · `delivery/`(계단의 전설) · `house/`(잡귀야 물러가라) — 게임마다 따로 쪽
- `privacy.html` — 개인정보처리방침 (한국어 + 영어, 구글 플레이 등록용)
- `assets/` — 달토끼·달 도트 그림, 게임 화면
- `CNAME` — 사이트 주소(도메인) 연결용 파일
